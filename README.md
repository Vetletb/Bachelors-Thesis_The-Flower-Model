# The Flower model

## Overview
This project is the code implementated for the Bachelor's thesis "Exploring Noise Robustness in Image Classification using Image Representations derived from a Shifting Focus Centre and a Predefined Filter Bank"

The source code is found in src/

in additional/ more experimental code used for development and testing is found.

## Installation

```bash
git clone https://github.com/Vetletb/Bacheloroppgave-gr82-feature-extraction.git
```

navigate to project root

```bash
pip install -e /
```

installs python package "flower_model"

## Prerequisites
- Python
- Pytorch module for python
- Pytest for running tests

## How to run
Import flower_model in python code
There are two public classes; CoeffPreProcessor and CoeffProcessor.
Use docstrings for usage
