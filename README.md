# Multidimensional Gabor-Like Filters Derived from Gaussian Functions on Logarithmic Frequency Axes

This repository contains the source files used to produce the figures in the article:

Devakumar, Dherik and Eidheim, Ole Christian (2024). Multidimensional Gabor-Like Filters Derived from Gaussian Functions on Logarithmic Frequency Axes.

arXiv link: https://arxiv.org/abs/2402.09419.

## Dependencies

- Python 3
- NumPy
- Matplotlib
- LaTeX

For the Python 3 dependencies, see also [requirements.txt](requirements.txt).

## Run Figure 1 experiments and save PDF files

<p><code>$ <b>python3 figure1.py</code></p>

## Run interactive demonstration related to Figure 1

<p><code>$ <b>python3 demo.py</code></p>

## Run Figure 2 experiments and save PDF files

<p><code>$ <b>python3 figure2.py</code></p>
